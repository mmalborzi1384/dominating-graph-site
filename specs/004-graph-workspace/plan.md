# برنامه

- هستهٔ مشترک رسم SVG/رأس و لایهٔ نمای۳بعدی؛ آداپترهای قبلی API سازگار دارند.
- چیدمان توپولوژیک خانواده‌ها، حفظ جایگاه‌های صریح مدل‌های غیرفامیلی.
- حذف مسیرهای نوشتن آزمایشگاه از UI؛ دامنهٔ قدیمی فقط برای سازگاری داده باقی می‌ماند.
- سازندهٔ قطعی n/γ با اثبات ساخت و بررسی فراگیر همهٔ ورودی‌های مجاز.
- minmax(0,1fr) و wrap در سوابق، بدون پنهان‌کردن overflow کل سایت.
- رگرسیون دامنه/مرورگر، بررسی دوتم/موبایل/کیبورد/نمای۳بعدی و گزارش antislop after.
