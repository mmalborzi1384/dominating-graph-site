# بررسی اصلاح‌های آزمایشگاه و ناوبری

پیگیری تأییدشدهٔ ممیزی پس از مرج PR14/15: سه یافته اصلاح و۱۶۷۷بررسی مرورگر پاس شد؛
گیت، اندازه‌ها، ثبت تعامل و محدودیت‌ها در
[گزارش پیگیری antislop](../../anti-slop/followup-001-2026-11-15.md) آمده است.
شرح زیر، سابقهٔ بررسی قبل از مرج است.

تاریخ۲۰۲۶-۱۱-۱۵؛ شاخه `codex/lab-graph-navigation`، بر پایهٔ کامیت `7c7d6cf` مربوط به
PR14 که هنگام این بررسی هنوز باز و مرج‌نشده بود. این اصلاح‌ها جدا ارائه می‌شوند.

آزمون مرورگر تازه، فایل‌های واقعی پروژه را زیر `/dominating-graph-site/` سرو می‌کند.
پروفایل موقت است و به دادهٔ مرورگر کاربر دست نمی‌زند. بررسی لمس شبیه‌سازی CDP است؛
دستگاه فیزیکی، میزبان خارجی و امتیاز Lighthouse/Web Vitals بررسی یا اندازه‌گیری نشده‌اند.
یک تلاش اجرای نام اشتباه `validate-records-browser.mjs` انجام نشد؛ فرمان صحیح موجود
`validate-apos-v3-browser.mjs` اجرا شد و۳۹بررسی پاس شد.

## ثبت تعامل‌ها، R-35

- دکمهٔ نقشه ← پنجرهٔ کوچک باز و مقصد جاری دارای فوکوس می‌شود.
- آموزش/تمرین/مسابقه/سوابق/آزمایشگاه ← هر پنج مسیر واقعاً فعال و پنجره بسته می‌شود؛
  فوکوس پس از آشکارشدن پنل به همان پنل می‌رود.
- کلید جهت ← مقصد انتخاب‌شده عوض می‌شود؛ Enter ← مقصد انتخاب و پنجره بسته می‌شود.
- بستن / Escape ← پنجره بسته، فوکوس به تریگر برمی‌گردد.
- لمس بیرون / خروج کیبورد از پنجره ← پنجره بسته می‌شود؛ فوکوس حبس نمی‌شود.
- نبود Popover API ← پنجره واقعاً نمایان است و Escape آن را می‌بندد.
- تصادفی درجه۱/۲/۳ و «بعدی» در هر دو بخش ← سؤال با همان درجه؛ فیلتر درجه۲ ←
  گزینه‌های نامرتبط غیرفعال، نه سؤال با درجهٔ نادرست.
- آغاز رسم n=2 و گاما1 ← دو رأس بدون یال و حالت اتصال؛ پاسخ خودکار تولید نمی‌شود.
- دو انتخاب رأس ← یک یال؛ رفتن به رسم فعلی ← یال حفظ می‌شود.
- بررسی/ثبت ← n و گامای واقعی بررسی و همان گراف ثبت می‌شود.
- هدف نامعتبر n=11 ← پیام خطا و گراف فعلی بدون تغییر.
- لمس رأس ← انتخاب واقعی؛ کشیدن لمسی ← جابه‌جایی واقعی بدون انتخاب متن؛
  هایلایت بومی خود رأس و تمام فرزندان شفاف است، فوکوس گرد کیبورد باقی است.
- reduced-motion سیستم ← حرکت پنجره خاموش؛ پیشرفت آموزش قبل/بعد برابر است.
- dropdownهای قدیمی تمرین/آزمایشگاه ← بالا/پایین باز می‌شوند، روی کنترل‌های پایین‌اند،
  Escape فوکوس را بازمی‌گرداند؛ drag قبلی کارگاه نیز پاس شد.

## مرز بازبینی

فایل‌های محتوا، شناسه/صورت سؤال، ارزیابی امتیاز، schema و مسیر APOS تغییر نکرده‌اند.
`.agent/` مستند عمومی است؛ `.codex/` و `.agents/` همچنان محلی و ignore هستند.
تغییر قانون‌نامه۱٫۳٫۰ فقط استثنای پنجرهٔ ناوبری غیرمودال درخواستی را ثبت می‌کند.
مرج و تأیید آموزشی/انتشار زنده جزو این درخواست نیست. یافته‌های after منتظر انتخاب کاربرند.
