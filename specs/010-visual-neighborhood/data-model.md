# Data model

Five named vertices, eight existing undirected roads, fixed places. Selection is null
or one known ID in closure memory. Disclosure and shared view preferences stay in DOM.
Return states: loading/fresh/returning/complete/unavailable, derived from current
curriculum, validateProgress and snapshot persisted/readStatus/dirty/conflict/needsMigration.
Destination #teach or unlocked unit. No score/time/schema/key/persistent flag introduced.
