# برنامه

- زوم در attachGraphView و API کوچک دوربین موجود؛ حفظ CTM و هندسهٔ اصلی SVG.
- Canvas دوبعدی مستقل با تعداد محدود رأس، DPR محدود و نرخ فریم محدود؛ بدون کتابخانه.
- توکن‌های مرکزی روز/شب و حذف شبکهٔ body؛ هماهنگی سطح‌ها از همان توکن‌ها.
- اعتبارسنجی واقعی زیرمسیر Pages، هر دو تم/عرض، توقف/کاهش حرکت، زوم و انتخاب،
  رگرسیون برد/هاشور و کنتراست؛ graphify update، گزارش antislop و PR بدون مرج.

پیگیری پس از مرج: افزایش blur مرکزی به۱۶px و پوشانندگی شیشه به۳۸٪ در دوتم؛
افزایش reach اتصال با همان progress نرم‌شدهٔ اسکرول و fade پیوستهٔ یال‌ها.
تست تعداد یال‌های قابل‌مشاهده در ابتدا/انتهای صفحه و ادامهٔ حرکت بدون ورودی.
راهنمای liquid-glass-design مربوط به APIهای بومی iOS است؛ برای وب، اصول tint،
خوانایی و یک لایهٔ مشترک با CSS موجود اعمال می‌شوند؛ وابستگی بومی اضافه نمی‌شود.
