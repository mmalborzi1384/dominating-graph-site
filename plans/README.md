## جهت بصری و دلیل تصمیم‌ها

کارگاه فارسی ریاضی برای دانش‌آموز دوازدهم؛ ENERGY3 / RHYTHM2 / MOTION2.

| تصمیم | دلیل |

| حفظ پالت و Vazirmatn | هویت تاییدشده و خوانایی فارسی؛ بازطراحی نیاز به تغییر برند ندارد |
| محوریت برد مشترک | دانش‌آموز تغییر رابطه را روی خود مدل می‌بیند و رفتار بین تب‌ها یکسان می‌ماند |
| گروه‌بندی ابزار | ساخت، تغییر و بررسی وظایف متفاوت‌اند و باید محل قابل پیش‌بینی داشته باشند |
| مسیر متصل APOS | نمایش پیش‌نیاز واقعی، بدون تبدیل درصد تکمیل به ادعای تسلط |
| خط زمانی فقط برای تلاش timestampدار | تاریخ و پیشرفت ساختگی وارد سوابق نمی‌شود |
| محله فعلی | تشبیه مکان و راه از محتوای خود محصول می‌آید؛ asset یا لوگوی تازه لازم نیست |
| حرکت کوتاه و سطح مات | توجه روی تغییر مسئله، خوانایی متن و کاهش فشار موبایل |

جست‌وجوی design-system مهارت UI خروجی عمومی Hero+Features و فونت لاتین داد؛ به دلیل ناسازگاری با اپ آموزشی فارسی پذیرفته نشد. جست‌وجوی product آموزشی حتی با بازنویسی تطبیق تاییدشده نداشت؛ بنابراین این پیشنهادها از معماری/جهت مصوب پروژه و قواعد عمومی مهارت‌اند، نه تطبیق ادعایی پایگاه محصول. جست‌وجوی motion تطبیق معتبر Reduced Motion و Excessive Motion داشت. خروجی نامرتبط progressive disclosure هم مبنای تصمیم قرار نگرفت.

## اصلاح روند در 2026-11-21

antislop در همه مراحل during است؛ منتظر ممیزی پس از اتمام نمی‌مانیم. ui-ux-pro-max برای ظاهر، Graphify برای دانش، Spec Kit برای برنامه‌ریزی و مهارت‌های تخصصی متناسب با نیاز استفاده می‌شوند. improve فقط مشاوره و بازبینی می‌کند.
