## Design read and purpose

The concrete five-place motif teaches adjacency through a real selection, not a generic
marketing graphic. Native disclosure keeps all five activity entrances compact; opening
it reveals the complete shared tools. Reserved copy sizes prevent a late compact-mode
collapse; no entrance choreography. Native Persian alternatives identify numbered beads
and provide touch/keyboard access. Existing Vazirmatn supports Persian reading. Existing
matte theme tokens isolate text/roads from the graph-world background. Selected bead and
incident-edge weight express state; no added glass, shadow, grid, icon or decorative motion.

## Recorded control click-through

- Native summary mouse opens; Space closes, Enter opens; selection retained. Tab enters shared viewport.
- Each of house/school/library/park/clinic via actual mouse selects exactly one and reports
  exact direct neighbors, highlighting only corresponding existing paths. No coverage hatches.
- SVG Enter and Space select/clear; native alternative Space selects; real CDP touch selects once.
- Reset clears selection and restores empty explanation; resets no teaching/practice state.
- Shared2Dzoom changes display; device toggle changes mode; focus opens; Escape restores.
- Shared3D opens and native label selects through original SVG;2D restores. WebGL-null
  fixture shows unavailable note and keeps2D functional. Graph-mobile validator covers rest of shared zoom/drag controls.
- Valid saved-unit CTA navigates to actual unlocked teaching unit; complete progress says
  review. Dirty/conflict/migration/invalid/unavailable snapshots use generic teaching link.
- Theme/motion changes retain map selection; exploration changes no repository state.
- Reconnect unsubscribes; destroy removes stage and disconnects shared observers.

## Recommendations and limits

No additional visual change recommended inside this phase. Separate maintenance suggestion:
update the obsolete navigation-lab validator to the already-approved free-lab contract;
its failure predates this branch and was not hidden. The previously documented shared
animation-cancellation timing issue remains a separate follow-up, not fixed here.

or screen-reader speech. 200% test is root-text enlargement/reflow, not native browser UI
zoom. Snapshots with progress flags are test fixtures, not educational evidence. Pages
is not deployed/verified by this unmerged PR. No merge or next-phase execution.
