# نتیجهٔ اصلاح سه یافتهٔ antislop

حالت after طبق انتخاب صریح همین گفتگو؛ کاربر انجام تمام فهرست audit-001 را تأیید کرد.
PR14 و PR15 پیش از این اصلاح‌ها طبق دستور او مرج شدند؛ این پیگیری جدا بازبینی می‌شود.

## فهرست نهایی

1. **R-03، اصلاح شد.** hit area شفافِ کارگاه منبع با اندازهٔ واقعی SVG تنظیم می‌شود؛
   در عرض۳۶۰ از۳۲٫۹۶ به۴۵پیکسل رسید. مهرهٔ قابل‌دیدن و پوشش تغییر نکردند. برای
   مدل پرتراکم، حداقل عرض از فاصلهٔ رأس‌ها محاسبه می‌شود؛ پیمایش داخل برد است.
   مدل‌های۱تا۱۶رأسی در تمرین/آزمایشگاه، دو تم و عرض۳۲۰/۳۶۰/۱۲۸۰ هدف≥۴۴پیکسل،
   بدون برخورد اولیه و بدون overflow سند داشتند. جابه‌جایی به لبه نیز هدف را نمی‌بُرد.
   Observer هنگام تعویض سؤال قطع می‌شود. چیدمانِ عمداً روی‌هم‌کشیده‌شده توسط کاربر
   از شرط «فاصلهٔ اولیه» جداست؛ ابزار هنوز ویرایش آزاد موقعیت را اجازه می‌دهد.
2. **R-39، اصلاح شد.** خودارزیابی در هر دو بانک label نمایان مرتبط دارد؛ labels.length=1
   و نام combobox شامل «ارزیابی پاسخ با معیار» است. سطر/ستون وزیر نیز label مرتبط
   دارند و کلیک label ورودی را فعال می‌کند؛ تغییر مختصات همان صفحهٔ واقعی را به‌روز می‌کند.
3. **R-10، اصلاح شد.** کارت‌ها، کنترل‌ها و بازشدن جزئیات blur ندارند. انیمیشن JavaScript
   تعویض تب نیز دیگر blur موقت تولید نمی‌کند. در هر پنج تب صفر لایهٔ blur و با پنجرهٔ
   ناوبری باز دقیقاً یک لایه ثبت شد. دو پالت و کنتراست متن روی زمینهٔ مات حفظ شدند.
   قانون‌نامه۱٫۴٫۰ و قرارداد رابط با تصمیم مصوب هماهنگ شدند.

## جهت و دلیل‌ها

خوانش اعلام‌شده پیش از ویرایش: فضای آموزش گراف فارسی برای دوازدهم، با هویت شبکه و
مهره‌های گراف‌نامه؛ ENERGY2 / RHYTHM2 / MOTION2. رنگ و Vazirmatn از توکن‌های موجودند.
اندازهٔ هدف مستقل از مهره است تا لمس بهتر شود و معنای پوشش عوض نشود. فاصلهٔ اولیه
و پیمایش داخلی برای تفکیک رأس‌های پرتراکم‌اند. label کنار ورودی، معنای آن را پیش از
تعامل روشن می‌کند. زمینهٔ مات برای خواندن/ویرایش طولانی است؛ تنها پنجرهٔ شناور، شیشه
دارد تا از صفحهٔ زیر متمایز شود. حرکت کوتاه تعویض تب و ورود مهره‌ها حفظ شده است.

## شواهد واقعی

| بررسی مرورگر | تعداد موفق |
| --- | --- |
| سه یافتهٔ تأییدشده |۴۹۲ |
| ناوبری/رسم/درجه‌ها/لمس |۹۵ |
| بازبینی APOS و dropdown بالا/پایین |۷۴۱ |
| مسیر کامل آموزش |۳۱۰ |
| سوابق و تبدیل داده |۳۹ |
| جمع |۱۶۷۷ |

تمام اجراهای نهایی صفر خطای Runtime و صفر شکست داشتند. تست‌های Node برای APOS v3
۲۸۹+۳۹۵، foundation۱۰۴، practice۳۷، competition۱۷۴، lab۲۱۱، records۹۰، random۱۱۶،
polish۴۲، teaching۵۴ و ساختار/اتصال۱۵۰سؤال نیز پاس شدند. syntax و whitespace بررسی شدند.

آزمون تازه یک خطای واقعی دیگر از همان یافته۳ پیدا کرد: blur موقت WAAPI روی کارت‌ها؛
رفع و همهٔ تست‌های مرتبط دوباره اجرا شدند. دو خطای اولیهٔ خود harness نیز اصلاح شدند:
MIME صفحهٔ اصلی سرور آزمایشی، و جست‌وجوی details در fixture وزیر که details نداشت.
تصاویر نهایی بعد از پایان ورود تدریجی مهره‌ها ثبت و نمای روز/شب موبایل بررسی شدند.

محدودیت: لمس با CDP در Chrome شبیه‌سازی شد؛ دستگاه فیزیکی، Safari/Firefox، مرور انسانی
تک‌تک۱۵۰سؤال، Windows/VPS و اندازه‌گیری عملکرد در این اجرا انجام نشدند. موفقیت انتشار
Pages برای SHA مرج‌شده از API تأیید شد؛ دریافت عمومی با timeout SSL ناموفق بود.
شرح در `specs/002-apos-teaching-v11/validation/publication.md` است؛ اصلاح‌های این گزارش
هنوز جزو آن SHA منتشرشده نیستند. این گزارش گیت سه اصلاح است، نه ادعای بی‌نقصی کل سایت.

## ثبت تعامل‌های محدودهٔ اصلاح

- ساخت خانواده با۱تا۱۶رأس ← همان تعداد و توپولوژی، هدف‌های جدا و داخل SVG؛ فقط برد پرتراکم پیمایش دارد.
- تغییر عرض بدون ساخت دوباره ← هدف لمس با مقیاس جدید تنظیم می‌شود.
- لمس بیرون از مهره ولی داخل هدف ← انتخاب واقعی رأس در هر دو بانک تغییر می‌کند.
- حالت یال، رأس a سپس c ← یال افزوده می‌شود؛ تکرار همان دو رأس ← حذف می‌شود.
- حالت جابه‌جایی، drag لمسی ← موقعیت واقعی تغییر می‌کند و متن انتخاب نمی‌شود.
- کلید جهت روی رأس ← حرکت و باقی‌ماندن فوکوس؛ رسیدن به لبه و resize ← هدف بریده نمی‌شود.
- نمایش معیار ← label نمایان مرتبط؛ انتخاب yes ← مقدار اصلی select به‌روز می‌شود.
- label سطر وزیر ← فوکوس input؛ سطر۲/ستون۵ ← وزیر در خانهٔ متناظر و پوشش واقعی صفحه.
- تعویض پنج تب/بازشدن dropdown/جزئیات ← blur صفر؛ پنجرهٔ نقشه ← فقط ظرف پنجره blur دارد؛ Escape ← بسته می‌شود.
- پیشرفت آموزش پیش/پس از این تعامل‌ها ← یکسان؛ آزمون‌های مستقل تبدیل/سوابق نیز پاس‌اند.
