# گراف‌نامه

پوستهٔ آموزشی فارسی و راست‌چین برای فصل دوم ریاضیات گسستهٔ پایهٔ دوازدهم: گراف و مدل‌سازی.

## وضعیت فعلی

پوستهٔ فاز اول و برش محدود برد در فاز دوم برای بازبینی پیاده‌سازی شده‌اند:

- پنج تب مستقل آموزش، تمرین، مسابقه، سوابق و آزمایشگاه با نشانی‌های hash.
- تم روز و شب با ذخیرهٔ انتخاب تم در localStorage.
- فونت محلی Vazirmatn و فایل‌های محلی KaTeX با نسخه، مجوز و checksum ثبت‌شده.
- نمایش سازگار با موبایل، جهت فارسی RTL و نماد ریاضی LTR.

جریان کامل تب‌ها هنوز پیاده‌سازی نشده است. در تب آموزش فقط یک برد نمونهٔ مستقل برای
بازبینی قرار دارد؛ مسیر APOS، مسابقهٔ گروهی، گزارش و انتقال داده شروع نشده‌اند.

برد نمونهٔ «کتابخانهٔ سیار در محله» از ساختار P5 سؤال Q048 استفاده می‌کند؛ زمینه و
چیدمان در `content/board-preview.json` جدا نگهداری می‌شوند. خواستهٔ احاطه‌گر، مینیمال
یا مینیمم را انتخاب و با لمس رأس/دکمهٔ مکان یا Enter/Space انتخاب کنید. پوشش زنده و
ارزیابی دقیق همهٔ زیرمجموعه‌ها، کیفیت ۰/۵/۱۰/۱۵ و راهنمای سه‌سطحی قابل بررسی‌اند.
تمرین راهنمای رایگان دارد؛ قاعدهٔ مسابقه سقف ۱۰، ۵ و صفر را به‌ترتیب اعمال می‌کند.
پاک‌کردن انتخاب، راهنماهای مصرف‌شده را پس نمی‌گیرد. نمایش پاسخ نمونه سقف نهایی صفر
را در قاعدهٔ مسابقه مصرف می‌کند. همهٔ این وضعیت‌ها موقت‌اند و ثبت یا تجمیع نمی‌شوند.

ظرف‌های رابط از پنل دقیق `docs/repo-patterns.md` با alpha برابر ۰٫۸۴ و blur برابر ۱۲px
استفاده می‌کنند؛ گراف و مهره‌ها مات‌اند. رنگ رأس از اندیس ثابت صفرمبنای آن در فهرست رأس‌ها
با فرمول u % 10 تعیین می‌شود. رأس انتخاب‌شده یکدست، پوشش تکی با هاشور مالک و پوشش
مشترک به بخش‌های مساویِ هاشور مالک‌ها نمایش داده می‌شود. رأس بی‌پوشش خالی می‌ماند و
فقط بعد از بررسی دور قرمز می‌گیرد. گذار تب/کارت/تم با
reduced-motion سازگار است. ویرایش یال، ساخت گراف و dragging مربوط به فاز بعدند.

## اجرا بدون بیلد

از ریشهٔ مخزن:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

سپس `http://127.0.0.1:8765/` را باز کنید. هر وب‌سرور استاتیک دیگر هم کافی است.
Python فقط برای پیش‌نمایش محلی است؛ محصول به Python، Node، نصب بسته یا بیلد نیاز ندارد.
بازکردن مستقیم `index.html` با `file://` پشتیبانی نمی‌شود؛ ماژول‌ها و فایل JSON از HTTP(S)
بارگیری می‌شوند. برای بررسی زیرمسیر، پوشهٔ والد مخزن را سرو کنید و مسیر مخزن را باز کنید.

GitHub Pages، Nginx/Apache لینوکس و IIS ویندوز باید همین فایل‌ها را سرو کنند؛ بازنویسی
مسیر و پردازش سمت سرور لازم نیست. فایل `.nojekyll` برای انتشار مستقیم فایل‌ها موجود است.
در IIS، نوع فایل‌های `.json`، `.js` و `.woff2` باید به‌ترتیب JSON، JavaScript و font/woff2
باشد. انتشار روی میزبان‌های واقعی هنوز انجام یا تأیید نشده است.

## ویرایش ظاهر و متن

| فایل | مسئولیت |
| --- | --- |
| `index.html` | ساختار فارسی، تب‌ها و متن جایگزین در صورت خطای بارگیری |
| `content/shell.json` | عنوان و توضیح قابل ویرایش هر تب |
| `assets/css/tokens.css` | تنها محل تعریف رنگ‌ها و خانوادهٔ فونت‌های پوسته |
| `assets/css/base.css` | دسترس‌پذیری و قواعد پایهٔ متن |
| `assets/css/layout.css` | چیدمان واکنش‌گرا و حالت تب فعال |
| `assets/css/graph.css` | تصویر جلد، برد انتخاب و ظرف‌های شیشه‌ای با fallback مات |
| `assets/js/domain/graph.js` | اعتبارسنجی گراف ساده و کلید توپولوژی |
| `assets/js/domain/evaluate.js` | بررسی همهٔ زیرمجموعه‌ها و هر پاسخ مینیمم معتبر |
| `assets/js/domain/scoring.js` | کیفیت پاسخ و سقف راهنما |
| `assets/js/ui/graph-editor.js` | برد SVG انتخاب رأس؛ بدون ویرایش توپولوژی |
| `assets/js/ui/board-preview.js` | اتصال نمونهٔ موقت برای بازبینی فاز دوم |
| `content/board-preview.json` | سناریو، نگاشت رأس/یال و چیدمان قابل ویرایش نمونه |
| `assets/js/ui/tabs.js` | جابه‌جایی تب با hash، کلیدهای جهت‌نما و Home/End |
| `assets/js/theme.js` | انتخاب تم پیش از رسم صفحه و ذخیرهٔ تنظیم پوسته |
| `assets/js/app.js` | اتصال پوسته، بارگیری متن و نمایش فرمول جلد |
| `assets/vendor/*/PROVENANCE.md` | نسخه، منابع رسمی، مجوز و SHA-256 فایل‌های همراه |

برای تغییر متن، `shell.json` و متن جایگزین مربوط در `index.html` را هماهنگ کنید.
رنگ یا فونت را در اجزای رابط یا داده‌های محتوایی هاردکد نکنید. تمام مسیرها نسبی‌اند.

در فاز اول فقط کلید `graph-learning:shell:v1:<base-path>` با ساختار `{version: 1, theme}`
ذخیره می‌شود؛ دادهٔ فعالیتی ایجاد نمی‌شود. در فاز ذخیره‌سازی، این تنظیم باید به envelope
طراحی‌شده منتقل و کلید موقت پوسته حذف شود؛ تا آن زمان repository و schema کامل ساخته نشده‌اند.
خطای خواندن/ذخیرهٔ تم درون صفحه اعلام می‌شود و رابط بدون ادعای ذخیرهٔ موفق کار می‌کند.

## بررسی همین فاز

تب‌ها، refresh، back/forward، لینک مستقیم و hash نامعتبر را در مرورگر موبایل و دسکتاپ
بررسی کنید. جهت‌نماها در نوار تب، Home/End، حرکت با Tab و focus قابل دیدن باید کار کنند.
تم را تغییر دهید و صفحه را تازه‌سازی کنید؛ انتخاب باید حفظ شود. در نبود مجوز ذخیره،
تغییر تم موقت است و پیام روشن نمایش داده می‌شود. فونت و فرمول باید بدون درخواست CDN
بارگیری شوند. عرض‌های مرجع ۳۶۰ و ۱۲۸۰ پیکسل‌اند.

بررسی‌های محلی سبک برای همین فایل‌ها:

```sh
node --check assets/js/app.js
node --check assets/js/theme.js
node --check assets/js/ui/tabs.js
```

Node.js 22+ فقط ابزار توسعهٔ اختیاری است. اسکریپت `scripts/validate-content.mjs` مربوط به
فاز بعد است و هنوز ایجاد نشده؛ مجموعه‌آزمون یا وابستگی Playwright در پروژه وجود ندارد.
برای بررسی سبک و مستقل ریاضی (بدون نصب بسته یا چارچوب آزمون):

```sh
node scripts/validate-graph.mjs
```

این اسکریپت همهٔ گراف‌های سادهٔ ۲ تا ۵ رأسی و گراف‌های آمادهٔ بانک را با روش مرجع
جداگانه بررسی می‌کند. شواهد واقعی فاز دوم در
`specs/001-persian-graph-learning/validation/phase-2.md` و بررسی پوسته در `specs/001-persian-graph-learning/validation/phase-1.md` ثبت می‌شود.

## روند توسعه

هر ویژگی یک PR مستقل و پیش از ادغام نیازمند بازبینی انسانی است. پس از هر تکهٔ تغییر کد:

```sh
graphify update .
```

این دستور ابزار توسعه است و شرط اجرای سایت نیست. قواعد پرس‌وجوی گراف و خواندن منبع در
`AGENTS.md` و قانون‌نامهٔ `.specify/memory/constitution.md` باقی است. مشخصات، برنامه،
قراردادها و وضعیت وظایف در `specs/001-persian-graph-learning/` قرار دارند.
