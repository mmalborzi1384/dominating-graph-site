# گراف‌نامه

وب‌سایت آموزشی فارسی و راست‌چینِ گراف و مدل‌سازی، فصل دوم گسستهٔ دوازدهم.
فایل‌ها مستقیماً سرو می‌شوند: بدون بیلد، دیتابیس یا سرویس پردازشی؛ ماندگاری فقط localStorage.

## وضعیت قابل بازبینی

هر پنج تب پیاده شده‌اند: آموزش APOS، تمرین، مسابقه، سوابق و آزمایشگاه.
آموزش دوازده فعالیت تألیفی دارد؛ هر بار فقط یک فعالیت نشان داده می‌شود، پاسخ درست
با یا بدون راهنما قدم بعدی را باز می‌کند و چهار مرحله هرکدام ۲۵٪ پیشرفت دارند.
فقط تکمیل و محل ادامه ذخیره می‌شوند؛ پاسخ، راهنما و امتیاز آموزش ثبت نمی‌شوند.
تمرین و مسابقه امتیاز دارند؛ مسابقه در هر دور سؤال‌های متفاوت با سختی یکسان می‌دهد.
آزمایشگاه پنج ایستگاه، سازندهٔ ۲–۱۰ رأس، ویرایش لمسی/کیبورد، گاما و چالش زمان‌دار دارد.
سوابق شامل تحلیل، شش ساحت، حذف انتخابی و ورود/خروج JSON است.

فاز ۸ سربرگ متحرک اختصاصی هر تب، گذار تب/شیشه، حرکت برد و بازخورد، شمارش امتیاز و
حلقهٔ پیشرفت را اضافه می‌کند. انتخاب‌گر کوچک بالای صفحه چهار سطح خاموش/کم/متوسط/کامل
دارد؛ انتخاب ذخیره می‌شود و reduced-motion سیستم همیشه حرکت را خاموش می‌کند.
حرکت‌ها محدودند و زمان ثبت/درستی پاسخ به پایان حرکت وابسته نیست.

**انتشار کامل هنوز تأیید نشده است.** بانک مرجع ۱٫۴ شامل ۱۵۰ سؤال کامل از نظر ساختار
است، اما ۴۰ شناسه در مجموعه‌های فعلی رابط مسیر دسترسی دارند. تکمیل اتصال همهٔ سؤال‌ها،
شکل‌های لازم، تطبیق کتاب و بازبینی آموزشی انسانی باقی‌اند. جزئیات در
[وضعیت محتوا](docs/content-status.md) و [گیت‌های انتشار](specs/001-persian-graph-learning/validation/release.md).

## اجرا بدون بیلد

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

سپس http://127.0.0.1:8767/ را باز کنید. Python صرفاً سرور پیش‌نمایش توسعه است؛ هر
وب‌سرور استاتیک کافی است. `file://` پشتیبانی نمی‌شود. KaTeX و Vazirmatn محلی‌اند؛
برای اجرای محصول نصب Node یا بسته لازم نیست. مسیرهای hash نیاز به rewrite ندارند.

## انتشار با کپی فایل‌ها

محتوای ریشه، `assets/`، `content/`، `docs/question-bank.json` و `.nojekyll` را حفظ کنید.
برای توزیع کامل منابع آموزشی، PDF و گزارش‌های docs نیز قابل ارائه‌اند.

- **GitHub Pages:** ریشهٔ شاخهٔ main را به‌عنوان منبع Pages انتخاب کنید؛ فایل‌های همین
  PR تا پیش از مرج به main روی Pages فعلی نیستند. بارگیری در زیرمسیر نام مخزن پشتیبانی می‌شود.
- **Linux/Nginx:** root یا alias را به پوشهٔ فایل‌ها بدهید، index را `index.html` بگذارید
  و فایل استاندارد `mime.types` را بارگذاری کنید. rewrite یا reverse proxy لازم نیست.
- **Linux/Apache:** DocumentRoot یا Alias به همان پوشه؛ `DirectoryIndex index.html` و
  MIME معمول فایل‌های استاتیک کافی است. حساسیت حروف نام فایل‌ها حفظ شود.
- **Windows/IIS:** سایت استاتیک و Default Document=`index.html`؛ در صورت نبود نگاشت،
  `.js` را `text/javascript`، `.json` را `application/json`، `.woff2` را `font/woff2`
  و `.wasm` را فقط در صورت اضافه‌شدن چنین دارایی‌ای `application/wasm` تنظیم کنید.
  نگاشت تکراری اضافه نکنید. محصول فعلی wasm ندارد و به مفسر سمت سرور نیاز ندارد.

پس از کپی، هر پنج hash، تازه‌سازی، JSON، فونت، KaTeX و ذخیره/بازیابی را بررسی کنید.
وضعیت فعلی آزمایش میزبان‌ها در [deployment.md](specs/001-persian-graph-learning/validation/deployment.md)
ثبت است؛ بررسی زیرمسیر محلی معادل تأیید IIS/Nginx واقعی نیست.
داده‌ها به origin و مسیر پایه وابسته‌اند؛ جابه‌جایی بین میزبان‌ها با خروجی/ورودی فایل است.

## ویرایش محتوا و ظاهر

| فایل | مسئولیت |
| --- | --- |
| `assets/css/tokens.css` | رنگ، فونت و زمان‌های مرکزی؛ پالت روز/شب |
| `assets/css/motion.css` | حرکت محدود، ریـل کوچک و reduced-motion |
| `content/motion.json` | متن سربرگ پنج تب |
| `content/teaching.json` | چهار ساختار APOS، دوازده فعالیت و گونه‌های پیوسته |
| `content/{practice,competition,lab,records}.json` | محتوای قابل ویرایش هر بخش |
| `docs/question-bank.json` | بانک مرجع ۱٫۴؛ شناسه‌ها و معنای منبع حفظ شوند |
| `assets/js/domain/` | منطق مستقل از DOM و ذخیره‌ساز |
| `assets/js/ui/` | برد، ریاضی، بازخورد، تب‌ها و حرکت مشترک |
| `assets/js/storage/` | اعتبارسنجی، تراکنش محلی و انتقال فایل |
| `assets/js/tabs/` | کنترلرهای پنج تب |

پالت دقیق و مهره‌ها در توکن‌ها هستند؛ رأس‌ها شیشه‌ای نمی‌شوند. اندیس ثابت رأس رنگ
آن را تعیین می‌کند؛ هاشور تک‌مالک و بخش‌های مساوی چندمالک حفظ می‌شوند.
تنظیم حرکت اختیاری و معتبر است؛ دادهٔ قدیمیِ بدون آن به متوسط برمی‌گردد. خروجی جاری
بانک ۱٫۴ قابل ورود مجدد است؛ بک‌آپ بانک قدیمی بدون مهاجرت معنایی بازبینی‌شده رد می‌شود.

## بررسی محلی و بازبینی

اسکریپت‌های توسعه بدون وابستگی‌اند؛ اجرای سایت به آن‌ها نیاز ندارد:

```sh
node scripts/validate-content.mjs --write
node scripts/validate-polish.mjs
node scripts/validate-graph.mjs
node scripts/validate-apos.mjs
node scripts/validate-foundation.mjs
node scripts/validate-practice.mjs
node scripts/validate-competition.mjs
node scripts/validate-lab.mjs
node scripts/validate-records.mjs
node scripts/validate-random.mjs
```

اعتبارسنج محتوا تا رفع گیت‌های انتشار خروج غیرصفر دارد؛ این شکستِ مستندِ دسترسی/شکل‌ها
را با نقص ساختاری بانک یکی نگیرید. راهنمای بررسی و محدودیت شواهد در
[quickstart](specs/001-persian-graph-learning/quickstart.md) است. هیچ Playwright یا بیلدی اضافه نشده.
هر فاز یک PR و یک بازبینی انسانی دارد؛ مرج تنها با اجازهٔ صریح کاربر.
پس از هر تکهٔ کد `graphify update .` اجرا شود؛ Graphify ابزار توسعه است، نه پیش‌نیاز محصول.
